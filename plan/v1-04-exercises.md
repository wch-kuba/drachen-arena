# Part 4 – Five exercises

**Goal:** all five exercise screens on top of the core engine. Each one mirrors the school test format.

← [Back to plan](../PLAN.md)

## 1. Selbstlaute, Zwielaute, Umlaute (choice)
- [ ] **Mode A:** show one letter or group (a, ei, ü, au, äu…) + audio → 3 big buttons: Selbstlaut (gelb) / Zwielaut (grün) / Umlaut (blau).
- [ ] **Mode B (school-test style):** a short sentence; child taps a letter or group and gives it a color. Tapping "ei" selects both letters as one group.
- [ ] Mode B check: show which ones were missed, with gentle highlighting.
- [ ] Mix modes A and B in a round.

## 2. Einzahl und Mehrzahl (typing)
- [ ] Show the picture, "ein Hut" → picture ×2, "viele ___".
- [ ] Child types the plural on the custom keyboard.
- [ ] Umlaut-plural hint: "Aus **u** wird **ü**…" with the vowel highlighted.
- [ ] Track the type of mistake (missing umlaut vs wrong ending) for v2 stats.

## 3. Fehlende Buchstaben (typing)
- [ ] Word with a gap: "M _ tze" + picture + audio.
- [ ] Gap = one vowel/umlaut or a group (ie, ei, au, eu, äu). Gap size shown.
- [ ] Child types only the missing letters; the full word is shown when correct.

## 4. Kurze und lange Selbstlaute (choice)
- [ ] Word shown + audio played automatically (replay button).
- [ ] Target vowel highlighted.
- [ ] Two buttons: **•** kurz / **–** lang (dot = short, line = long).
- [ ] After answering, the mark appears under the vowel in the word.

## 5. Wörter mit ie (typing)
- [ ] Picture only (+ optional audio after try 1 as a hint).
- [ ] Child types the whole word.
- [ ] Hint flow: "Es hat ein langes i…" → first letter → answer.

## Done when
Each exercise works with 5+ test items on the iPhone, with the keyboard, hints and audio.
