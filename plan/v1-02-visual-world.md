# Part 2 – Visual world

**Goal:** one clear look for Drachen-Arena, decided before building screens and making images.

← [Back to plan](../PLAN.md)

## Tasks

### Input from the parent
- [ ] Kid's favorite colors.
- [ ] Favorite animals, things, themes (e.g. space, ocean, unicorns, football).
- [ ] Anything the kid dislikes or is scared of (keep it out).
- [ ] Optional: a drawing by the kid, or a toy they love (photo).

### Direction (run `/impeccable` new-work)
- [ ] World concept: what the "Arena" is and what the 5 lands are (one per exercise).
- [ ] Palette, including the 3 test colors: **gelb** = Selbstlaut, **grün** = Zwielaut, **blau** = Umlaut. They must match the school test.
- [ ] Typography: a school-like print font (single-storey "a" like the worksheet font), large sizes.
- [ ] Image style for all AI art (one style prompt, reused in Part 7).
- [ ] Key screens sketched: home/world map, exercise screen, keyboard, reward moment, dragon collection.
- [ ] Motion: what happens on right answer, almost right, wrong, egg hatching.
- [ ] Sound: short effects (optional, with mute).

### Record
- [ ] DESIGN.md written (tokens, components, image style prompt).

## Done when
DESIGN.md exists and the parent has seen and liked the direction.
