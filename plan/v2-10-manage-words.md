# Part 10 – Manage words

**Goal:** the parent adds school words in under a minute each.

← [Back to plan](../PLAN.md)

## Tasks
- [ ] Word list per exercise, searchable, with filters (active / from parent / problem words).
- [ ] Add/edit form per exercise type, with only the fields that type needs:
  - Laute: letter/group + category, or a sentence.
  - Mehrzahl: singular (with article) + plural.
  - Lücke: full word + which letters are the gap (tap letters to mark).
  - Kurz/lang: word + target vowel + short/long.
  - ie: word + picture.
- [ ] Live preview of how the child will see it.
- [ ] Picture for new words: decide the fallback (emoji picker and/or camera/photo upload, resized on device).
- [ ] Turn words on/off instead of deleting (keeps progress); delete only for parent-added words.
- [ ] "Diese Woche in der Schule" tag → those words come first in rounds.

## Done when
The parent adds 5 new words and the child sees them in the next round.
