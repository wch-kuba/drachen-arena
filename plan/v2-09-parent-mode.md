# Part 9 – Parent mode & settings

**Goal:** a separate area for the parent that the child can't open by accident.

← [Back to plan](../PLAN.md)

## Tasks
- [ ] Parent gate: long-press (2 s) on a small icon → an adult-level sum (e.g. 7 × 8). No PIN to forget.
- [ ] Parent home: Wörter, Import, Fortschritt, Backup, Einstellungen.
- [ ] Settings: child's name, sound on/off, speech speed, round length (5/10/15).
- [ ] Settings: turn exercises on/off (follow what school covers now).
- [ ] Parent UI can be plainer and denser than the game UI (operate mode).
- [ ] Note in the UI: "Änderungen nur in der installierten App" (Safari storage is separate).

## Done when
The parent can get in, change the name and round length, and the child can't get in by tapping around.
