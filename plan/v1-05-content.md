# Part 5 – Seed content

**Goal:** ~150–200 real Klasse 2 items, focused on the kid's known mistakes, checked by the parent.

← [Back to plan](../PLAN.md)

## Tasks
- [ ] Generate a first draft with a script calling Claude Opus 5.5 with structured JSON output, using the lists below as the brief. Then check it by hand before the parent reviews it.
- [ ] Write `src/content/seed.json` (or one file per exercise).
- [ ] **Laute:** all Selbstlaute (a e i o u), Umlaute (ä ö ü), Zwielaute (au ei eu äu ai), plus ~20 short sentences for mode B (include the 3 test sentences' style, not the same sentences).
- [ ] **Mehrzahl:** ~40 nouns, at least half **umlaut plurals**: Hut→Hüte, Laus→Läuse, Korb→Körbe, Wand→Wände, Ball→Bälle, Baum→Bäume, Haus→Häuser, Maus→Mäuse, Topf→Töpfe, Zahn→Zähne, Stuhl→Stühle, Fuß→Füße, Hand→Hände, Kopf→Köpfe… plus regular ones (Katze→Katzen, Auto→Autos, Hund→Hunde).
- [ ] **Lücke:** ~40 words; start with the missed ones: Mütze, Birne, Kirsche, König, then Milch, Bürste, Löwe, Pilz, Tür, Vögel, Schüssel, Möhre…
- [ ] **Kurz/lang:** ~30 words in clear pairs (Ofen/offen, Hüte/Hütte, Beet/Bett, Schal/Schall, Miete/Mitte, Kahn/kann, Stiel/still).
- [ ] **ie:** ~30 picturable words: Biene, Brief, Ziege, Spiegel, Tier, Fliege, Wiese, Riese, Knie, Dieb, Lied, Sieb, Stiefel, Kiefer…
- [ ] A rule `hint` for every item where it helps.
- [ ] Tag items (`umlaut-plural`, `missed-on-test`) so they come first.
- [ ] Export as a readable table (Markdown/CSV) and send it to the parent for review.
- [ ] Apply the parent's fixes.

## Done when
The parent has confirmed the word list matches school material.
